# 길담 — 길가 쓰레기통 지도

HTML + CSS + JavaScript로 만든 간단한 시연용 웹앱입니다. 프레임워크, npm 설치, API 키, 빌드가 필요 없습니다.

## 실행

`dist/index.html`을 브라우저에서 열면 됩니다. 인터넷 연결이 있어야 지도 배경이 보입니다.
현재 위치 기능을 안정적으로 사용하려면 HTTPS 배포 주소 또는 localhost에서 실행하세요.

```powershell
cd 'C:\Users\user\Documents\ChatGPT\기후변화\gildam\dist'
python -m http.server 8080
```

브라우저에서 http://localhost:8080 을 여세요.

## 파일

- `dist/index.html`: 한국어 화면, 제보·참여·도움말 창
- `dist/style.css`: PC·모바일 디자인
- `dist/app.js`: 거리 계산, 위치, 검색, 사진 GPS 비교, 검토, 보상, 상태 저장
- `dist/bins.js`: 초기 쓰레기통 배열. 현재 서울시청 주변의 **가상 예시 8개**이며 실제 위치를 나타내지 않습니다.
- `dist/vendor/`: Leaflet 1.9.4(BSD-2-Clause), exifr 7.1.3(MIT)와 라이선스. 버전을 고정해 포함했습니다.
- `verify.cjs`: Node.js가 있을 때 `node verify.cjs`로 거리·중복·24시간 만료·검토·보상 등 핵심 로직을 검사합니다. 실행에는 Node.js가 필요하지 않습니다.

## 동작

1. 위치 사용을 누르거나 지도를 클릭해 기준 위치를 고릅니다. 반경·이름·이용 가능 여부로 검색합니다.
2. 가까운 정상 쓰레기통을 추천합니다. 거리는 Haversine 공식으로 계산한 **직선거리**입니다. 실제 최단 보행 경로 계산은 포함하지 않으며, 도보 길 안내는 Google 지도로 연결됩니다.
3. 쓰레기통을 선택하고 가득 참을 누르면 현재 시각과 24시간 뒤 만료 시각을 저장합니다. 중복 제보는 거절하고 만료 시각을 연장하지 않습니다. 만료 여부는 매 표시 시각에 계산하고, 1분마다 및 재접속 시 정리합니다. 앱을 닫아도 저장된 만료 시각은 유지됩니다.
4. GPS가 포함된 JPG(8MB 이하)를 올리고 이름·위치를 입력합니다. 사진 GPS와의 거리가 100m를 넘거나 25m 이내 중복 위치가 있으면 거절합니다. GPS 없는 사진도 거절합니다.
5. 위치 확인을 통과하면 **검토 대기** 상태가 됩니다. 사진 EXIF는 조작 가능하므로 실제 존재 및 야외 여부를 자동 검증했다고 표시하지 않습니다.
6. 나의 참여 → 검토 기능 체험하기에서 사진을 보고 승인/반려를 체험합니다. 승인된 제보만 지도에 반영되고, 승인 5건마다 100P, 최초 5건에 배지가 표시됩니다. 실물 보상이 아닌 시연용 숫자입니다.

## 실제 운영 전 필요한 작업

- `bins.js`의 배열을 출처·기준일이 확인된 지자체 공공데이터로 교체
- 서버 DB와 사진 저장소, 사용자 로그인 및 서버 측 검증
- 권한이 분리된 운영자 검토, 사진 중복·EXIF 조작·허위 제보 대응
- 여러 사용자의 제보 공유 및 서버에서 보상 중복 지급 방지

현재 데이터·검토·포인트는 **해당 브라우저의 localStorage**에만 저장됩니다. 다른 기기나 사용자와 공유하지 않으며 캐시 삭제 시 사라집니다. 사진은 GPS 확인 후 긴 변 640px의 미리보기로 줄여 저장하며 원본 파일을 서버로 보내지 않습니다. 브라우저 저장 한도를 넘으면 저장하지 않고 안내합니다. 일반 상태는 최근 가득 참 제보가 없다는 뜻이며, 실제 비어 있음을 보장하지 않습니다.

지도는 [Leaflet](https://leafletjs.com/)과 [OpenStreetMap](https://www.openstreetmap.org/copyright), 사진 GPS는 [exifr](https://github.com/MikeKovarik/exifr)를 사용합니다. 실제 대규모 운영 시 지도 타일 제공자의 이용 정책에 맞는 서비스가 필요합니다.
